De quem é cada prefixo

Você define uma vez e vale para o cadastro inteiro. Fica guardado neste navegador.
i
Quatro esquemas de filtro são reconhecidos sozinhos — MANN, MAHLE, FLEETGUARD e HENGST — porque o próprio fabricante codifica assim e a descrição confirma. O resto dos prefixos é fornecedor que só você sabe qual é. Quando o código começa com letra, a chave é o prefixo (todo REX… é do mesmo fornecedor). Quando o código é só número, a chave é o grupo — o prefixo não diria nada. Cada linha que você preencher marca todos os itens dela de uma vez, e o pedido de compra passa a sair separado por fornecedor.
